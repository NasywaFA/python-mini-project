# Python Playground

This repository is a collection of small Python projects created for learning, experimenting, and improving Python skills — ranging from automation, mini-games, simple utilities, and experiments.

Each folder contains an independent project with its own purpose.

---

##  How to Run

### 1 Clone the repository
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name

### 2 Install dependencies (if required)
Some projects have their own dependencies.

Example for autoclicker:
cd autoclicker
pip install -r requirements.txt

If a project does not have requirements.txt, it only uses Python standard library and does not need extra installation.

### 3 Run a project
Example:

python autoclicker/autoclicker.py

cd minigame
py foundtheletter.py

## Project Details
🔹 autoclicker
An automation script that simulates mouse clicks automatically.

Install dependencies:
pip install -r requirements.txt

🔹 minigame
A small mini-game project written in Python.

Files:

foundtheletter.py → main game

libs.py → helper functions

🔹 songlyrics
A simple script related to song lyrics.
